Synla

Synla fills in your timesheet from what you actually did on your computer. It also shows the work that never makes it into a plan: helping colleagues, urgent problems, chasing answers and fixing other people's errors. Everything stays on your own computer.

Version 1, a work in progressSynla works and is tested on every change, and it runs every day on Windows. It is still young, so expect changes, and use it on a computer you control.

What it does

Synla asks, you tap

  • Sorts what it is sure of, asks about the restA few questions a day, with its best guess already picked. A number for the project, a letter for the kind of work, Enter to save. Fewer questions every day as it learns.
  • Keeps things apart when you jump aroundAn evening of email, a game install and real work becomes a stretch of each, not one bundle. Open any stretch to see every window in it.
  • Shows the unplanned workHelping someone, urgent problems, chasing answers and fixing others' errors, and what keeps coming back.
  • Fits your roleThirteen roles, from accountant to purchaser, each with its own kinds of work. Rename any of them.
  • A timesheet ready to reportA week per project, with codes for your reporting system, and a record book that seals each week.
Privacy and security by design

Built for the employee, not for monitoring

There is no account, no server and no admin view, so there is nothing to collect or compare across people. The full list of checks, each with a test, is on GitHub.

Who can open it

  • The pages answer on your own computer only, and need a key that Synla gives your browser. Another account on the same computer has no key.
  • Only Synla's own script runs. Everything shown is escaped, so a window name that looks like code stays text.
  • No network traffic. Nothing is sent anywhere.

What it keeps, and for how long

  • Window names are deleted after 14 days. Your hours stay.
  • Other people's names in window titles are hidden before anything is stored.
  • Delete your data from Synla's own page at any time. Deleted window names are overwritten on disk.

Integrity

  • Every file is written whole or not at all, and the last good copy is kept.
  • Each week is sealed in a record book with a fingerprint, so a later change shows.
Never recordedKeystrokes, screenshots, the clipboard, file contents, sound and web addresses. Password managers, private browsing, banks, unions, health sites and similar are stored as Private, with no name.
Decisions

The trade-offs behind it

ChoiceGainPrice
Everything stays on your computerNothing to leak, and nothing a manager can seeNo team view and no sync between computers, by design
Python's standard library onlyNothing else to install, and easy for IT to read and approveMore code written by hand, and a plainer interface
Its own recorder on WindowsSynla decides what is stored and for how longOn Mac and Linux it reads ActivityWatch instead
Window names kept for 14 daysLess personal data over timeOlder days can't be sorted again window by window
A sealed record bookAnyone can check that a week was not changed laterA correction after sealing shows as a change
Try it

A made-up week in one command

You need Python 3.10 or newer, and nothing else. On Windows, type py where it says python.

python -m synla demo

To use it for real on Windows, see the README. IT gets one page on what Synla reads, what it never does, and how to remove it. Don't install it on a work computer without written approval.
